# 质量与版式

## 硬约束

- 只写：`docs/agents/**`、`AGENTS.md`；仅当 `dual_claude=true` 时写 `CLAUDE.md`
- 禁止修改业务代码（如 `backend/`、`common/`、`console/`、`app/`、`src/` 等源码目录）
- 引用的源码路径必须在**当前仓库**真实存在；否则标「待确认」或删除臆造项
- 禁止编造 HTTP 方法、入参、表字段、模块名、状态迁移、调用链下一跳
- 禁止把其它仓库的业务域、模块名、中间件名单套到当前仓库
- **四层有则写、无则标「本仓库无」**；未命中的层禁止建页、禁止用其它系统的实例当标题
- SVG 遵守 `references/diagrams.md`：全景图企业分层风（浅灰底、层色实心卡片）；流程图白底描边（橙判断 / 蓝步骤）；禁止 GitHub 深色主题
- `AGENTS.md` ≤ 300 行；详情只放相对链接，不粘贴长清单
- 「禁区」「历史包袱」禁止本 skill 填写具体事实；已有人写实文则保留
- 怎么跑只从本仓库已有 README / compose / 脚本**抄**启动命令与端口；禁止执行 brew/apt/composer install、禁止启动应用、禁止在业务仓库新建 `scripts/`
- 传输层类型（`Request` / `Form` / `DTO` / `VO` / `Resource`）只写 api-list，禁止当 data-model 表；禁止为「以 DB 为准」去读 SQL / migration
- 清单超上限必须按本节「清单上限」砍；禁止 200 项「建议补」附录
- 每步结束后自检；不通过则本步重做再进入下一步
- 判断不清先做合理选择，在最终 summary 标「需人工确认」；**唯独 `flows` 的 propose 阶段必须打断等拍板**（覆盖「不要中途提问」）
- Markdown 遵守本节「文档版式」：结构清楚即可，禁止装饰
- 资产互校未过：禁止写「已自洽 / 覆盖齐全」；缺口必须进 summary 表

## 文档版式（给人扫、给 AI 解析）

目标是**结构清楚**，不是杂志排版。AI 认的是标题层级、表格列、相对链接、稳定文件名；堆装饰会降低命中率。

### 要做

- 每个 md **一个 H1**；H2 分块；H3 仅深页（步骤 / 实现细节）；禁止 H4+
- 文首 4～7 行元信息：系统 / 剖面 / 更新时间 / 真源 / 条目数（没有的项省略，不要编）
- 清单、契约、域、调用栈一律用**表**；职责写一句话，禁止用段落堆字段
- 超过约 8 个分组的长清单：H1 后先放「分组锚点索引表」，再写各节
- 节与节空一行；表前一行写「合计 N」（能数出来才写数字）
- 缺口 / 待确认用引用块：`> 缺口：…`；表内单元格写 `待确认`；**每页缺口引用块 + 缺口表行合计 ≤10**，超出改成「另有 N 处不展开」
- 状态用纯文字：`有` / `无` / `待确认` / `已深挖` / `等待用户选择` / `已过期`

### 不要做

- emoji、徽章、HTML、CSS、`<details>` 折叠正文（部分 Agent 会跳过折叠内容）
- 用 mermaid 围栏代替 `flow.html`（`.mmd` 作渲染源可以）。全景图仍是 SVG，不要改成 mermaid
- 每小节都画 `---`；关键事实只放图里、md 不写
- 把同一事实复制成两套不同表述

## 质量门

- 路径真实存在于当前仓库
- SVG 遵守 `diagrams.md`：全景图浅灰底+层色实心卡+左轨+一行图例；流程图白底描边；无 `#0d1117` 深底、无侧栏长文
- api-list 不编造契约
- data-model 以本仓库 Model 为准，不使用 migrations / SQL；传输层类型不进本页；字段 API 以 `detect.md` 本轮剖面节为准
- 框架只看根目录 `composer.json`；目录与 Model API 以本轮官网摘录 ∩ 仓库实有路径为准。禁止用目录名猜框架、禁止套其它框架记忆
- 新框架只在 `detect.md` 包名表加官网链接，禁止新写一节目录清单
- 域名称、V 页标题来自探测，不来自其它系统的记忆
- 未命中的 F/L/V/X 不建页
- **propose 不得产出** `{domain}-{slug}.md` 与任何功能流程图
- 无 `domain=` 时禁止新建 `flows/{domain}.md`（`full` / `flows` 皆然）；旧骨架页不删
- 已有可用候选页且仍等待选择、用户未说刷新：只复述，不重扫、不改该页
- **deep** 必须有 `S*` 步骤表 + 实现细节 + 一份 `flow.html`。禁止用多张流程图 SVG 代替
- 图节点、步骤表、调用栈共用同一套 `S*`；字段不进图
- `flow.html` 默认只显示 5～9 个主步骤，子流程折叠，点击展开。同出口的条件收成一个菱形；只改中间数值的判断留在分支表。会改下一步的判断必须是菱形，禁止收成副行。图上不写行号
- 深页步骤表、分支表、调用栈都有本轮打开过的 `路径:行号`。没有行号的判断没有画成菱形
- `AGENTS.md` 有「先查哪里」。里面的工具和 `rg` 目录是本轮探测到的，不是别的仓库的习惯
- `refresh=off` 时没有重写已存在的清单页、全景图、深页。缺页可以新建
- ER ≤ 12 实体
- AGENTS.md ≤ 300 行
- `mode=surfaces` / `mode=domains` / `mode=full` 结束后必须存在 `docs/agents/01-domains/INDEX.md`，且域表至少 1 行真实路径
- md 遵守「文档版式」：一个 H1、清单用表、无 emoji/HTML/`<details>`
- `mode=full` 且本轮新建了 api-list：必须有 `critical-paths.md`（≤8）且交出互校表；无 api-list 则按「降级」。`refresh=off` 且这些页已在：不重跑互校，summary 写「未重跑互校」
- api-list 有「暴露」列（对外 / 内部）和「冒烟候选」节（≤5，只列不跑）
- 三张全景图通过 `diagrams.md` **内容 review**，不过则本步重画
- 禁区纪律见本节「禁区与历史包袱」
- `mode=full` / `mode=entrypoint`：风险地带页 ≤10 且全标待确认；`AGENTS.md`「怎么跑」是静态摘录，不是安装指南
- 清单条数遵守本节「清单上限」；超了必须砍完再 summary
- `refresh` 行为遵守本节「已有页不整页重写」

## 先查哪里

`AGENTS.md` 在「核心架构」之后必须有这一节。接口表、模型表、全景图是某次扫描的快照，不是调用图。和代码冲突时以代码为准。

工具只写本轮真能调用、且 `list_projects` 对得上本仓库的，禁止假设已经安装：

1. 本轮按 `detect.md`「知识图谱」对上了 codebase-memory → 表里写 codebase-memory 和项目名
2. 仓库有 `.codegraph/` → 表里写 CodeGraph
3. 当前环境能调用 GitNexus → 表里写 GitNexus
4. 都没有 → 只写 `rg -n`。目录必须是本轮探测到的路由目录、Model 目录、Consumer 目录

```markdown
## 先查哪里

调用关系和「改了谁会坏」不要读接口表、模型表。

| 要问的 | 怎么查 |
|---|---|
| 谁调用这个类 | （codebase-memory，项目名写上；否则 CodeGraph 或 GitNexus；都没有则 `rg -n "ClassName" --glob "*.php"`） |
| 路由 / 命令入口 | `rg -n` + 本轮探测到的真实目录 |
| 业务判断链 | 已深挖的 `flow.html`。没有则先 `mode=flows`，不要从算子目录硬扫 |
```

`refresh=off` 且 `AGENTS.md` 已存在：只补或更新这一节。其它节不动。禁区、历史包袱仍按本节「禁区与历史包袱」。

新建或 `refresh=force` 重写 api-list、data-model 时，文首加一行：`性质：扫描快照。调用关系以代码为准，见 AGENTS.md「先查哪里」。`

## 行号证据

适用：深页步骤表、分支表、调用栈、核心链路的「依据」列。api-list、data-model 不要求每行行号。

- 格式：`路径:行号`。路径相对仓库根。行号是本轮 Read 看到的条件或调用所在行
- 禁止写「见某文件」。禁止用文件第 1 行凑数。禁止编造行号
- 该行对不上表里的类名、方法名或条件字段：单元格写 `待确认`。这个判断禁止画成 `flow.html` 的菱形
- 行号只写在 md。图上不写
- 深页已有 `## 人工补充`：重写步骤时整节原样保留，放在文末

`refresh=cited`：不改写句子。只打开表里的 `路径:行号`。文件没有、行号超出、该行不再含表里的类名或条件字段 → 该行状态改为 `已过期`。不重画 `flow.html`。summary 写过期行数，并写「图未更新」。

## 已有页不整页重写

| refresh | 行为 |
|---|---|
| `off` | 缺的页按 mode 新建。已有的清单、全景 SVG、ER、域索引、critical-paths、risk-zones、forbidden-candidates 不改。深页和 `flow.html` 也不改，除非本轮点名了 `feature=`。`AGENTS.md` 只补「先查哪里」 |
| `cited` | 不新建清单，不重画图。只按「行号证据」把对不上的行标 `已过期` |
| `force` | 按该 mode 整页重写它允许写的文件。禁区、历史包袱、`## 人工补充` 仍不覆盖 |

用户点名 `feature=` 做 deep：只重写这一个功能的深页和 `flow.html`，不顺手重写清单。

`flows` 的「刷新候选」只重算等待中的候选行，已深挖行保留 slug / 链接 / 状态。不要把它当成 `force`。

禁止在 `off` 时为了补全把 api-list 或全景图再扫一遍。

## 资产互校（硬门）

触发：`mode=full` 波次 2；`mode=surfaces` 且已有 `data-model.md`；`mode=data` 且已有 `api-list.md`。  
对照结果写入 summary，并写入 `docs/agents/INDEX.md` 缺口。禁止只口头说「大致对齐」。

| 左 | 右 | 通过 | 失败时（只改文档，禁止改业务代码） |
|---|---|---|---|
| api-list 入参/返回里**像持久化实体**的短名 | data-model 类/表 | 有定义，或单元格标「待确认：命名不一致」 | 补模型索引行，或改接口文案去掉臆造名 |
| architecture / module-deps 核心卡片标题 | `01-domains` 入口路径或本仓库真实目录 | 每个核心卡对得上路径 | 改图或改域索引；废弃模块改旁路卡，不当核心 |
| 冒烟候选 | api-list 实有行 | ≤5 且路径/方法能在清单打开 | 重选；禁止编造未扫到的接口 |
| critical-paths 起点 | api-list 或 cli-and-consumers | 起点是本仓库真实入口 | 改链路表，不编造入口 |

**不互校进模型页**（传输层，只留 api-list）：短名以 `Request` / `Form` / `DTO` / `VO` / `Resource` / `Serializer` 结尾，或 Yii 无 `tableName()` 的表单 Model。误把这类写进 data-model → 从模型页删掉，改回 api-list。

有未闭环缺口时：INDEX 覆盖率写缺口（≤10 行）；summary 禁止「资产已自洽」。

## DTO 与 Model

两套模型职责不同，分开写：

| 层 | 写在哪 | 真源 | 禁止 |
|---|---|---|---|
| 持久化 | `data-model.md` + ER | 本仓库 Model / ActiveRecord（本轮剖面 ∩ 实有路径） | 读 `migrations/`、SQL、把 Request 当表 |
| 传输 | `api-list.md` 入参/返回列 | 路由 + Controller 方法签名里本轮打开过的类型 | 把 DTO 字段合并进 Model 表、为对账去翻 DDL |

data-model 文首必须写：`真源：Model（不含 migration / SQL）。传输层见 api-list。`  
扫到 `*Request` / `*Form` / `*DTO` / `*Resource` / Yii 无 `tableName()` 的表单：不建表行。需要指出时最多在文末缺口写「未当表：FooRequest」≤10 条。

## 禁区与历史包袱

`AGENTS.md` / `CLAUDE.md` 的「禁区」「历史包袱」两节：

- 已有人写实文（不是「待团队补充」且不止一句占位）→ **原样保留，禁止覆盖**
- 否则只写：`待团队补充。本 skill 禁止把猜测写成事实。`
- **禁止**填写对接方、事故经过、不能改的字段、隐性约定等具体条目

候选线索最多 **8** 条，只写 `docs/agents/03-deep-dives/forbidden-candidates.md`，每行状态 `待确认`。来源限：代码注释（`不要删` / `FIXME` / `HACK` / `兼容` / `临时方案`）和可选 `git log` 标题（`回滚` / `hotfix`）。**禁止**把本页抄进禁区正文当成事实。

```markdown
# 候选禁区（待确认）

- 探测时间：
- 说明：来自注释或提交标题，不是已确认禁区。禁止抄进 AGENTS.md「禁区」当事实。

| 证据 | 摘录 | 为何像禁区 | 状态 |
|---|---|---|---|
| `path:line` | … | … | 待确认 |
```

## 风险地带

路径固定：`docs/agents/03-deep-dives/risk-zones.md`。给人填禁区用，**不替代**禁区正文。

- ≤ **10** 条，全标 `待确认`；宁少勿多
- 只收**结构线索**，与候选禁区分工：注释/提交标题 → `forbidden-candidates.md`；类名/目录/双写/开关 → 本页。同一 `path:line` 已进候选禁区则本页不重复
- 类型只许四选一：`兼容层` / `双写` / `开关` / `废弃`
- 来源限定点 Grep（类名 `Compat*` `Legacy*` `*Compat*`、`双写`、`灰度`/`feature.?flag`/`Toggle`、`@deprecated`/`已废弃`）。禁止把「看起来不优雅」写成风险
- **禁止**抄进 `AGENTS.md`「禁区」当事实

```markdown
# 风险地带（待确认）

- 探测时间：
- 说明：动了可能出事的结构线索，不是已确认禁区。禁止抄进 AGENTS.md「禁区」当事实。

| 类型 | 证据 | 摘录或类名 | 为何像风险 | 状态 |
|---|---|---|---|---|
| 兼容层 | `path` | … | … | 待确认 |
```

`mode=full` 波次 2 必写（扫不到则写「本轮未见」空表，不要编）。`mode=entrypoint`：页不存在才补写；已存在则只链接（用户说「刷新风险地带」除外）。

## 怎么跑（静态摘录）

只出现在 `AGENTS.md` / 可选 `CLAUDE.md` 的「怎么跑」节，**不新建**运行手册、不写业务仓库脚本。

允许读：`README*`、`docker-compose*.yml` / `compose.yaml`、已有 `Makefile` / `composer.json` `scripts` / `package.json` `scripts`、README 里写明的 artisan/think/yii 命令、`.env.example` 里明确的监听端口。  
禁止：执行安装或启动、编造未写明的 `php artisan serve` / 默认端口、生成 `scripts/start.sh`、把安装/启停/冒烟执行做成这个 skill 的步骤。

```markdown
## 怎么跑

- 真源：（本仓库已打开的文件名，没有则写「未见」）
- 本 skill 不安装依赖、不启动应用

| 做什么 | 命令或端口 | 出处 |
|---|---|---|
| 启动 | `…` | `README.md` |

> 缺口：仓库未见启动命令则整表一行 `待确认`，禁止用框架默认值充数。
```

表 ≤ **8** 行。每轮 entrypoint **按真源重写**本表，避免留下上次编造的端口。

## 清单上限

凡「推荐 / 候选 / 缺口 / 核心」类清单必须有数字上限。AI 看到具体数字才会筛选。

| 清单 | 上限 | 超了 |
|---|---:|---|
| 核心链路 | 8 | 砍掉账号详情、纯列表分页 |
| 冒烟候选 | 5 | 重选；登录占 1 条（有鉴权时） |
| 候选禁区 | 8 | 留证据更硬的 |
| 风险地带 | 10 | 四类尽量不重复堆同一类 |
| 怎么跑表 | 8 | 只留启动 / 端口 / 文档主命令 |
| 每页缺口引用块 + 缺口表行 | 10 | 前 10 + 「另有 N 处不展开」 |
| flows 候选 | 3～5 | 其余进未展开 |
| flows 未展开表 | 10 | 「其余 N」 |
| V 实现列出 | 20 | 「其余 N 个见目录」 |
| ER 实体 | 12 | 非核心只索引不进 ER |
| 怎么跑之外的「建议补 / 建议关注」附录 | 10 | **禁止** 200 项附录 |

**域索引**是实有清单，不是推荐清单：实有域全列，禁止为「好看」删域。域数量 **>8** 时 H1 后先放分组锚点索引表，再按组写表。

## 核心链路

路径固定：`docs/agents/03-deep-dives/critical-paths.md`。

- ≤ **8** 条，宁少勿多；必须是「改造时容易出问题」的链路，不是全部 CRUD
- 不写测试、不 curl、不启动应用
- 每条用表：链路名、起点（方法+路径或 CLI）、关键节点、成功终点、依据（已有文档或本轮打开过的路径）
- `mode=full` 必写；`mode=entrypoint` 仅当该页不存在且已有 api-list 时补写，已存在则只链接、不重写（用户说「刷新核心链路」除外）

## 降级

- 域过大：候选仍限 3～5；其余进未展开
- 配置读不全：写「已知 + 待确认」，禁止假完整
- 剖面无法判定：走 `detect.md` 的 generic 节，summary 标需人工确认
- F 链路追断：写到最后一个可打开的类，下一跳标「待确认」
- V 过多：细节页列前 20；图上主路径 + 一条对照 + 「其它 N」
- 子流程一次展开仍铺满屏幕：先把同出口判断收成一个菱形，再往里嵌套折叠。禁止拆成多张 SVG，也禁止把会改下一步的判断并进副行或「+N」
- 分支表里会改下一步的行，在 `flow.html` 展开后没有对应菱形：本步重画
- 长流程若默认就把全部判断铺开：收成主步骤 + 折叠子流程
- 无 api-list：不写 critical-paths，summary 标缺口，禁止编造链路
- 缺口超过 10：只留 10 条 + 「另有 N 处不展开」，禁止把互校表整表粘进 INDEX
- 风险地带扫不到：写「本轮未见」，禁止用「重构风险高」这类空话充数
- 怎么跑无真源：一行待确认，禁止用框架教程里的默认命令

## Summary 模板

```markdown
# Codex Map summary
- system / 剖面 / mode / domain / feature：
- phase：propose | propose-reuse | deep | cited | n/a
- 并行：是/否；子代理列表（A diagrams / B surfaces / C data / D domains / flows-propose…）与各自结果：
- 探测到的业务域：
- 四层探测：F= / L= / V= / X=
- propose 时：候选 slug 列表（等拍板）；reuse 时写来源文件：
- deep 时：深挖的 slug + md + `flow.html` 路径：
- 写入文件列表：
- 各文件一句话摘要：
- 互校：通过 / 有 N 处缺口 / 未重跑互校
- 核心链路条数：
- 禁区：占位 / 已保留人写 / 候选 N 条待确认
- 风险地带：N 条待确认 / 本轮未见
- 怎么跑：已摘录（真源文件名）/ 待确认
- refresh：off / cited / force
- 图谱：已用（project 名）/ 未索引已跳过 / 不可用
- 过期：N 行 / 未核对；cited 时写「图未更新」
- 清单：未超限 / 砍掉了哪些 / off 跳过了哪些已有页
- 需人工确认：
```
